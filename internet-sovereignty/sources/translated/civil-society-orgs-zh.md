# 研究数字权利的公民社会组织

## 1. 公民实验室 (Citizen Lab)

**来源:** https://citizenlab.ca/

### 关于

公民实验室是多伦多大学芒克全球事务与公共政策学院的跨学科研究机构。他们汇集法律、计算机科学、网络安全、政治学和社会科学领域的专业知识，调查21世纪的复杂问题。

**使命:** 为公民社会提供反情报服务——调查数字生态系统中对民主、人权和全球安全的新型威胁。

### 研究重点领域

- **定向监控** - 调查针对公民社会的政府和企业监控工具
- **虚假信息** - 分析信息操纵和影响力行动

### 最新研究报告（截至2026年1月）

#### 1. 从抗议到危险：Cellebrite被用于针对约旦公民社会
**日期:** 2026年1月22日  
**研究领域:** 定向监控

通过多年调查，公民实验室发现约旦安全机构已部署Cellebrite公司制造的取证提取产品，用于针对公民社会的设备。这些调查结果与有组织犯罪和腐败报道项目（OCCRP）的报道同步发布，其中包括对部分受害者的采访。

#### 2. 我们说你想要革命：PRISONBREAK——一场旨在推翻伊朗政权的人工智能驱动影响力行动
**日期:** 2025年10月14日  
**研究领域:** 虚假信息

信息的控制和战略性操纵长期以来在伊朗伊斯兰共和国与其政治对手（包括以色列）之间的地缘政治和意识形态竞争中发挥作用。此前公民实验室的研究揭露了伊朗的虚假信息活动，但在此次调查中，他们将焦点转向地缘政治竞争的"另一方"。他们分析了一项影响力行动，评估认为该行动很可能由以色列政府实体或与其密切合作的私人承包商执行。

#### 3. 同海新钓：俄罗斯政府关联的社会工程攻击针对应用专用密码
**日期:** 2025年6月18日  
**研究领域:** 定向监控

2025年5月，俄罗斯军事行动知名专家凯尔·吉尔斯（Keir Giles）遭到高度复杂和个性化的钓鱼攻击。攻击者使用公民实验室此前未观察到的方法，冒充美国国务院员工，说服吉尔斯先生创建并发送其电子邮件账户的应用专用密码，从而绕过多因素认证。谷歌发现并阻止了此次攻击，将其归因于俄罗斯国家支持的行动者。

## 2. Access Now（立即访问）

**来源:** https://www.accessnow.org/

### 关于

Access Now 捍卫并扩展处于风险中的个人和社区的数字权利。通过结合直接技术支持、战略倡导、草根资助以及RightsCon等会议活动，他们为数字时代的人权而战。

Access Now 是一个全球性组织，团队成员遍布五大洲，在纽约、圣何塞（哥斯达黎加）、布鲁塞尔、柏林、突尼斯、德里、内罗毕和马尼拉设有办事处。

### 核心项目

1. **RightsCon** - 全球领先的数字时代人权峰会
2. **数字安全热线** - 为各地区处于风险中的人权捍卫者提供全天候援助
3. **资助计划** - 支持为数字权利奋斗的草根组织和一线机构

### 关注领域

- **言论自由** - 对抗数字审查，在全球推进言论自由
- **网络断网** - 记录并对抗互联网封锁
- **数据保护** - 保护个人数据和隐私权

## 3. #KeepItOn（保持连接）运动

**来源:** https://www.accessnow.org/campaign/keepiton/

### 关于

#KeepItOn 联盟汇集了来自世界各地的数百个公民社会组织及其盟友——包括政府、国际机构、媒体、私营部门等——共同为终结网络断网而战。

Access Now 于2016年发起 #KeepItOn 运动，动员全球民众、社区和公民社会力量对抗网络断网。如今，该联盟已联合超过345个国家级、国际级、区域级和地方级组织，成为全球推动终结网络断网的领先联盟。

### 什么是网络断网？

网络断网被定义为"有意中断互联网或电子通信，使其无法访问或实际上无法使用，针对特定人群或特定地点，通常是为了控制信息流动。"

其表现形式多样：
- 全面网络中断
- 限速（降低网速）
- 平台封锁

### 网络断网的重要性

网络断网始终是对人权的攻击。当人们断开连接时，会影响生活的方方面面：
- 工作和教育
- 医疗和银行服务
- 新闻和言论自由
- 社区组织
- 人权侵犯的记录
- 在冲突和危机期间获取救命信息和人道主义援助

### 断网追踪优化项目 (STOP)

Access Now 与 #KeepItOn 联盟的合作伙伴共同在STOP数据集中记录经核实的网络断网事件。自2016年开始，STOP提供了全球断网规模、类型和严重程度最完整的记录。
