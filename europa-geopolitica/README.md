# Europa Geopolitica - 欧洲地缘政治研究文献

## 概述

欧洲地缘政治（Europa Geopolitica）是研究欧洲在全球政治格局中的地位、战略利益、安全挑战以及与其他大国关系的学科领域。随着俄乌战争、美欧关系变化以及中国崛起，这一领域的研究变得尤为重要。

## 核心研究主题

### 🔵 欧盟战略自主 (EU Strategic Autonomy)
欧盟在安全、防务、经济和技术领域追求更大自主权的努力。

### 🔵 跨大西洋关系 (Transatlantic Relations)
美欧关系的演变，特别是在特朗普政府时期的变化与挑战。

### 🔵 欧洲安全架构 (European Security Architecture)
俄乌战争后欧洲安全格局的重塑。

### 🔵 中欧关系 (EU-China Relations)
欧洲应对中国崛起的策略，包括清洁技术竞争、供应链安全等。

### 🔵 欧盟扩大 (EU Enlargement)
西巴尔干、乌克兰、摩尔多瓦等国家的入盟进程。

### 🔵 地缘经济 (Geoeconomics)
经济工具在地缘政治博弈中的运用，如制裁、贸易政策等。
